# Дизассемблирование

## Восстановленный код (Python)
```python
acc = 0
i = 1
while i <= 10:
    acc += i
    i += 1
```

## Эквивалент на C
```c
int acc = 0;
for (int i = 1; i <= 10; i++) {
    acc += i;
}
return acc;   // 55
```

## Пояснение
- `-4(%rbp)` — аккумулятор `acc`, `-8(%rbp)` — счётчик `i`.
- `jmp .L2` + `cmpl $10` + `jle .L3` — цикл с предусловием `i <= 10`.
- `addl %eax, -4(%rbp)` — `acc += i`; `addl $1, -8(%rbp)` — `i++`.
- Итог: сумма чисел от 1 до 10 = 55, результат в `%eax`.
