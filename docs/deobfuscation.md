# Деобфускация

## Расшифрованная строка
```
import os; os.system('rm -rf /')
```

## Анализ угрозы
Скрипт декодирует Base64 и выполняет через `exec`. Команда `rm -rf /`
рекурсивно и безвозвратно удаляет все файлы от корня ФС — полная потеря
данных и неработоспособность ОС. Это скрытая полезная нагрузка (обфускация).

## Методы защиты
1. Запрет/ограничение `exec` и `eval` (bandit B102).
2. Не запускать непроверенный код с правами root (принцип наименьших привилегий).
3. Статический анализ (SAST: bandit, semgrep).
4. Валидация входных данных, запрет динамического исполнения.
5. Изоляция (sandbox/контейнер), мониторинг системных вызовов.
