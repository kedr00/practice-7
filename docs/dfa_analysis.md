# DFA-анализ

## Def-Use цепочки
| Переменная | Def | Use |
|---|---|---|
| log_entry | стр.3, стр.9 | стр.11 |
| status | стр.5 | стр.9, стр.12 |

## Дефекты
- **Дефект 1 (UnboundLocalError):** `status` определяется только при `amount > 0`; при `amount <= 0` обращение к ней в стр.9/12 падает.
- **Дефект 2 (Dead Store):** `log_entry = "Start processing"` (стр.3) перезаписывается до чтения.
- **Дефект 3 (Resource Leak):** файл открыт (стр.10), но не закрыт.
